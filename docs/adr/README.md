# ADR

작업 내용, 설계 판단, 리팩토링 결과를 기록하는 디렉터리다.

ADR 파일은 `YYYY-MM-DD-짧은-제목.md` 형식을 사용한다.

## ADR에 담을 내용

각 ADR은 다음 내용을 포함한다.

- 배경: 어떤 문제나 요구사항 때문에 작업했는지 설명한다.
- 구현 내용: 실제로 무엇을 변경했는지 정리한다.
- 에이전트 리뷰 내용: `docs/code-review-prompt.md`에 따라 3명의 병렬 에이전트에게 리뷰 받은 내용을 요약한다.
- 최종 판단 근거: 리뷰와 구현 결과를 바탕으로 왜 이 선택을 했는지 기록한다.
- 장단점: 선택한 방식의 이점과 감수해야 할 비용 또는 한계를 함께 적는다.
- 베스트 프랙티스 진전 판단: 마지막에는 이번 작업이 프로젝트를 베스트 프랙티스에 한발짝 더 가깝게 만들었는지 판단한다.

## 템플릿

```md
# 제목

## 배경

## 구현 내용

## 에이전트 리뷰 내용

## 최종 판단 근거

## 장단점

## 베스트 프랙티스 진전 판단
```
